# Telegram Media & Earnings Bot

Готовый Telegram-бот на Python 3.11+ / aiogram 3 / SQLite.

## Возможности

- Скачивание видео по ссылке через `yt-dlp` (TikTok, YouTube, Instagram и другие поддерживаемые yt-dlp источники).
- Поиск музыки через iTunes Search API — без отдельного API-ключа.
- Профиль пользователя: баланс, начислено зарплатой, кошелёк для вывода.
- Выдача зарплаты/начислений администратором с указанием причины.
- Вывод средств: заявка приходит владельцу с кнопками `✅ Одобрить` / `❌ Отклонить`.
- Просмотр пользователей владельцем, поиск пользователя по Telegram ID.
- Настройки суммы минимального вывода и лимита загрузки.
- SQLite — ничего отдельно устанавливать не нужно.
- Все настройки вынесены в `.env`.

## Быстрый запуск

1. Создайте бота через @BotFather и получите `BOT_TOKEN`.
2. Установите Python 3.11+ и FFmpeg.
3. Распакуйте проект.
4. Скопируйте `.env.example` в `.env`.
5. В `.env` укажите:
   - `BOT_TOKEN=...`
   - `OWNER_ID=8464597898`
6. Установите зависимости:
   `pip install -r requirements.txt`
7. Запустите:
   `python bot.py`

### Docker

Если на сервере есть Docker:

`docker compose up -d --build`

FFmpeg уже устанавливается в контейнер.

## Важно про загрузки

Telegram имеет ограничения на размер файлов в зависимости от типа Bot API/окружения. В проекте есть настройка `MAX_DOWNLOAD_MB`. Если ролик больше лимита, бот сообщает пользователю, что файл слишком большой.

`yt-dlp` может потребовать обновления или дополнительные cookies для отдельных платформ. Это ограничение самого источника, а не базы/баланса бота.

## Музыка

Кнопка «🎵 Поиск музыки» использует iTunes Search API. Пользователь вводит исполнителя или трек, бот показывает найденные композиции и ссылки на Apple Music.

Если позже понадобится полноценный поиск/скачивание музыки, лучше подключить отдельный легальный музыкальный API/провайдера и не хранить чужие аудиофайлы на сервере.

## Админ

Владелец: `OWNER_ID=8464597898`.

Админ-панель:
- список пользователей;
- поиск по Telegram ID;
- начисление зарплаты;
- просмотр баланса;
- просмотр заявок на вывод;
- изменение минимальной суммы вывода.

Все административные действия проверяются по Telegram ID.

## Структура

- `bot.py` — основной код.
- `database.py` — SQLite и операции с пользователями/выводами.
- `downloader.py` — загрузка через yt-dlp.
- `music.py` — поиск музыки.
- `.env.example` — настройки.
- `requirements.txt` — зависимости.
- `Dockerfile` / `docker-compose.yml` — запуск на VPS.
